# Русская локализация All the Mods 10

Неофициальный русский overlay для **All the Mods 10 7.3**. Он устанавливается поверх оригинальной сборки и не содержит модов,
JAR-файлов, сохранений, настроек лаунчера или самой сборки.

## Совместимость

- All the Mods 10: **7.3**
- Minecraft: **1.21.1**
- NeoForge: **21.1.247**
- Язык игры: **Русский (Россия)**

Другие версии ATM10 не поддерживаются: обновление сборки может изменить ключи, книги, задания и KubeJS-скрипты.

## Покрытие

- 340 установленных модов и компонентов получили новые или дополненные внешние переводы.
- Стандартные языковые ключи: **151 251 / 151 251**.
- FTB Quests: **8 701 / 8 701** ключей заданий.
- Patchouli: **1 793 / 1 793** переводимых JSON-путей.
- GuideME/Markdown: **320 / 320** страниц.
- Также переведены руководства Oracle Index, Modonomicon, Immersive Engineering, CC:Tweaked, Tombstone, XNet и другие.
- Все изменения сделаны внешними ресурсами; JAR-файлы не изменялись.

Полный список охваченных модов приведён в [TRANSLATED_MODS.md](TRANSLATED_MODS.md).

## Установка

1. Установите чистую ATM10 7.3 и закройте игру.
2. Сделайте резервную копию экземпляра сборки.
3. Скопируйте **содержимое** каталога `overrides/` в корень экземпляра ATM10 с заменой совпадающих файлов.
4. Запустите игру и выберите русский язык.

Пример для Linux/WSL:

```bash
rsync -a overrides/ /путь/к/экземпляру/ATM10/
```

Overlay содержит только 2 789 файлов, которые отличаются от оригинальной ATM10 7.3. Неизменённые русские файлы, уже входящие
в сборку, намеренно не дублируются. Устаревший объединённый `config/ftbquests/quests/lang/ru_ru.snbt` также не включён:
используются актуальные разделённые файлы FTB Quests.

## Важная особенность

Справка CC:Tweaked, руководство XNet, книга Herbs & Harvest и несколько жёстко заданных текстов KubeJS не имеют полноценного
механизма выбора локали. Эти файлы заменяются глобально и предназначены для русскоязычного экземпляра сборки.

## Состав репозитория

- `overrides/` — устанавливаемые файлы перевода;
- `TRANSLATION_FILES.txt` — точный разрешённый список файлов относительно `overrides/`;
- `TRANSLATED_MODS.md` — список охваченных модов;
- `SOURCE_VERSIONS.md` — зафиксированные версии и контрольные суммы;
- `CONTRIBUTING.md` — правила изменения переводов.
