Программа "peripherals" выводит все периферийные устройства, доступные этому компьютеру.
Периферия — внешние устройства, с которыми компьютеры и черепахи CraftOS взаимодействуют через API peripheral.
Введите "help peripheral", чтобы узнать об использовании API peripheral.
Введите "help drives", чтобы узнать о дисководах.
Введите "help modems", чтобы узнать о модемах.
Введите "help monitors", чтобы узнать о мониторах.
Введите "help printers", чтобы узнать о принтерах.
