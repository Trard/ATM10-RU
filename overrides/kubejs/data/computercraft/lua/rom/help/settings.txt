Функции API настроек:
settings.get( name, [default] )
settings.set( name, value )
settings.unset( name )
settings.load( path )
settings.save( path )
settings.clear()
settings.getNames()

Настройки по умолчанию:
shell.autocomplete - включает автодополнение в оболочке.
lua.autocomplete - включает автодополнение в программе Lua.
edit.autocomplete - включает автодополнение в программе Edit.
edit.default_extension - задаёт расширение по умолчанию для файлов, созданных программой Edit
paint.default_extension - задаёт расширение по умолчанию для файлов, созданных программой Paint
bios.use_multishell - включает Multishell на улучшенных компьютерах, черепахах, карманных и командных компьютерах.
shell.allow_disk_startup - если к компьютеру подключён дисковод с диском, содержащим сценарий 'startup', разрешает автоматически запускать этот сценарий при включении компьютера.
shell.allow_startup - если в корне компьютера есть сценарий 'startup', разрешает автоматически запускать его при включении компьютера.
list.show_hidden - определяет, будет ли программа List показывать скрытые файлы.
