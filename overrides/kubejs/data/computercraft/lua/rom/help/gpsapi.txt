Функции API GPS:
gps.locate( timeout )

Функция locate отправляет сигнал ближайшим серверам GPS и ждёт ответов до истечения времени ожидания. Если получено достаточно ответов для определения положения этого компьютера, функция вернёт координаты x, y и z, иначе — nil. Если координаты серверов GPS настроены неправильно, результаты будут неточными.
