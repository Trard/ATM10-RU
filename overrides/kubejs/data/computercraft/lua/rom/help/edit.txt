edit — текстовый редактор для создания и изменения программ или текстовых файлов. Создав программу с помощью edit, введите её имя в оболочке, чтобы запустить её. Чтобы научиться программированию, можно открыть в edit любую встроенную программу.

Пример:
"edit hello" открывает для редактирования файл с именем "hello".
