Функция os.pullEvent() приостанавливает программу до возникновения системного события. Первым возвращаемым значением будет имя события, а за ним — его аргументы.

Некоторые возможные события:
"char" — с клавиатуры введён текст. Аргумент — введённый символ.
"key" — на клавиатуре нажата клавиша. Аргументы — код клавиши и признак повторного нажатия. Сравните код со значениями API keys, чтобы определить нажатую клавишу.
"key_up" — клавиша на клавиатуре отпущена. Аргумент — числовой код клавиши. Сравните его со значениями API keys, чтобы определить отпущенную клавишу.
"paste" — с клавиатуры пользователя вставлен текст. Аргумент — вставленная строка текста.

События только для продвинутых компьютеров:
"mouse_click" — пользователь нажал кнопку мыши. Аргументы: button, xPos, yPos.
"mouse_drag" — пользователь переместил мышь с зажатой кнопкой. Аргументы: button, xPos, yPos.
"mouse_up" — пользователь отпустил кнопку мыши. Аргументы: button, xPos, yPos.
"mouse_scroll" — пользователь прокрутил колёсико мыши. Аргументы: direction, xPos, yPos.

Другие API и периферийные устройства создают собственные события. Подробности приведены на соответствующих страницах справки.
