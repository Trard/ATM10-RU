Проводные и беспроводные модемы — периферийные устройства CraftOS. Введите "help peripheral", чтобы узнать, как подключаться к периферии через Peripheral API. При подключённом модеме peripheral.getType() возвращает "modem".

Методы модемов:
open( channel )
isOpen( channel )
close( channel )
closeAll()
transmit( channel, replyChannel, message )
isWireless()

События модемов:
"modem_message" возникает при получении сообщения по открытому каналу. Аргументы: name, channel, replyChannel, message, distance.
