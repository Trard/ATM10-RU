# МЭ-восстановитель кристаллов

<BlockImage id="extendedae:crystal_fixer" scale="8"></BlockImage>

МЭ-восстановитель кристаллов ремонтирует и улучшает блок почкующегося истинного кварца.

Для работы ему нужны энергия и <ItemLink id="ae2:charged_certus_quartz_crystal" />. Нажмите по устройству правой кнопкой
мыши с <ItemLink id="ae2:charged_certus_quartz_crystal" />, чтобы вставить кристалл.
