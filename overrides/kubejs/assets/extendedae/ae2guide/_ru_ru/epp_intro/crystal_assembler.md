# Кристаллический сборщик

<Row>
<BlockImage id="extendedae:crystal_assembler" scale="8"></BlockImage>
</Row>

Расширенные устройства слишком сложны для обычного верстака, поэтому для создания большинства из них нужен
кристаллический сборщик.

**Примечание: грань с экраном не может подключаться к сети.**

Он также выполняет некоторые преобразования из мира, например создание флюикса.
