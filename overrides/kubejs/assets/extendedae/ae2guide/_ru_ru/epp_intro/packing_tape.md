# Упаковочная лента МЭ

Упаковочная лента МЭ упаковывает установленное в мире МЭ-устройство в предмет.

<Row>
<ItemImage id="extendedae:me_packing_tape" scale="4"></ItemImage>
<ItemImage id="extendedae:package" scale="4"></ItemImage>
</Row>

## Упаковка

Нажмите лентой правой кнопкой мыши по МЭ-устройству, крадучись, чтобы получить упакованный предмет. Все настройки и
содержимое устройства сохранятся. Это особенно удобно при переносе МЭ-системы.

Учтите, что лента поддерживает только устройства из списка; этот список изменяется в настройках.

## Распаковка

Нажмите правой кнопкой мыши с упакованным предметом так, словно размещаете соответствующий блок или кабельную часть.
Устройство будет восстановлено из упаковки.
