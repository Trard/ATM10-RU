# Изменитель конфигурации

Изменитель конфигурации — инструмент для массового изменения хранилищ конфигурации.

<ItemImage id="extendedae:config_modifier" scale="4"></ItemImage>

Нажмите им правой кнопкой мыши, чтобы открыть интерфейс.

## Использование

Изменитель быстро правит хранилища конфигурации, например хранилище интерфейса, в соответствии со своими настройками:
может установить максимальное количество предметов или полностью удалить их.

Нажмите изменителем по целевому устройству в мире — блоку или кабельной части, — чтобы изменить его конфигурацию.

## Настройки

Есть две основные настройки: **режим изменения** и **величина изменения (X)**.

Режим переключается кнопкой.

![Интерфейс изменителя](../pic/cm.png)

- Сложить/вычесть/умножить/разделить: применить соответствующую операцию с X к заданному количеству.
- Максимум: установить максимальное значение.
- Минимум: установить минимальное значение.
- Задать: установить значение X.
- Очистить: удалить все настроенные предметы.
