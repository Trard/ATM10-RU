# МЭ-ячейка пустоты

Карманный конденсатор для накопителя.

<ItemImage id="extendedae:void_cell" scale="4"></ItemImage>

Перед использованием ячейку пустоты необходимо разметить в <ItemLink id="ae2:cell_workbench" />. Она удаляет всё,
соответствующее фильтру, либо преобразует подходящие предметы в <ItemLink id="ae2:matter_ball" /> или
<ItemLink id="ae2:singularity" />, подобно <ItemLink id="ae2:condenser" />.

Нажмите по ней правой кнопкой мыши, чтобы открыть интерфейс настройки.
