Помимо <ItemLink id="ae2:energy_card" />, все беспроводные терминалы AE2WTLib можно улучшить с помощью
<ItemLink id="ae2wtlib:quantum_bridge_card" /> и объединить в <ItemLink id="ae2wtlib:wireless_universal_terminal" />.

Как и <ItemLink id="ae2:wireless_terminal" /> из AE2, такой терминал можно открыть назначенной клавишей и поместить в
слот Curios, если установлен мод с поддержкой API Curios.

Беспроводные терминалы также привязываются, как обычный <ItemLink id="ae2:wireless_terminal" />, с помощью
<ItemLink id="ae2:wireless_access_point" />.

## Терминалы из дополнений

Большинство беспроводных терминалов из других дополнений также работает с
<ItemLink id="ae2wtlib:wireless_universal_terminal" />.

## Терминалы, несовместимые с универсальным терминалом

<ItemLink id="ae2:wireless_terminal" /> нельзя использовать в <ItemLink id="ae2wtlib:wireless_universal_terminal" />:
он не даёт преимуществ перед <ItemLink id="ae2:wireless_crafting_terminal" /> и не поддерживает
<ItemLink id="ae2wtlib:quantum_bridge_card" />.
