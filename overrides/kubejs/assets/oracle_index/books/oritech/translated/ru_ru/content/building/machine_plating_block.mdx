В Oritech есть несколько облицовочных блоков для строительства заводов.
Они хорошо подходят для полов, стен и конструкционных корпусов.

Для каждого облицовочного блока существуют варианты **плиты**, **ступеней** и **нажимной пластины**.

### Варианты облицовки

*   **[Облицовка механизмов](@oritech:machine_plating_block)**: стандартная облицовка для корпусов механизмов.
У неё чистая гладкая текстура, хорошо сочетающаяся с механизмами Oritech.
*   **[Железная облицовка](@oritech:iron_plating_block)**: более тёмная и грубая облицовка промышленного класса.
Хорошо подходит для зон тяжёлой промышленности и несущих конструкций.
*   **[Никелевая облицовка](@oritech:nickel_plating_block)**: светлая коррозионностойкая облицовка с лёгким желтоватым оттенком.
Подходит для чистых помещений и зон специального оборудования.
*   **[Углеродная облицовка](@oritech:carbon_plating_block)**: современная высокопрочная тёмная облицовка.
Позволяет добавить контраст и оформить передовой комплекс в тёмных тонах.
