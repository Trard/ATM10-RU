Дополнение скорости сокращает время обработки в механизме.
При стандартном сложении эффектов оно даёт +50% скорости, то есть
механизм работает на 150% обычной скорости. Рецепт, обычно занимающий
100 тактов, завершится примерно за 67 тактов.

Такое ускорение снижает энергоэффективность,
увеличивая расход энергии механизма на 20%.
На один механизм можно установить несколько дополнений скорости,
ещё сильнее повысив общую скорость.

Подходит для всех механизмов, потребляющих энергию каждый такт работы.

---

**Умножение скорости обработки**

При использовании нескольких дополнений их бонусы скорости складываются.
Например, два дополнения дают общий бонус +100%, поэтому механизм
работает на 200% скорости, а рецепт на 100 тактов завершается за 50.
Это значительно ускоряет обработку ценой существенно
большего энергопотребления.
