Ресурсные узлы — бесконечные источники сырья, которое добывается с помощью
[бедрокового экстрактора](@oritech:deep_drill_block). Эти неразрушимые узлы встроены в бедрок.

Чтобы найти узлы, ищите на поверхности [рудные валуны](@oritech:world_ores).
Они отмечают ресурсный узел, расположенный прямо под ними в бедроке.

<center>
<ModAsset location="oritech:area/resource_node" width={700} />
</center>

Ресурсные узлы существуют для нескольких материалов: железа, меди, золота,
никеля, платины, урана и даже редких самоцветов, таких как алмазы.
Для разработки такого узла бур должен достигать слоя бедрока.
