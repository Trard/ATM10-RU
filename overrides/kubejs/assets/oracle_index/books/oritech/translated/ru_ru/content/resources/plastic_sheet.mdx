Пластик — полезный полимер для изоляторов, корпусов и множества компонентов среднего и высокого уровня.

В Oritech есть два основных способа производства пластика:
1. **Биологический путь**: обработайте [упакованную пшеницу](@oritech:packed_wheat) с водой в [центрифуге](@oritech:centrifuge_block),
чтобы получить сырой биополимер. Затем снова центрифугируйте его с водой для получения пластиковых листов.
2. **Нефтяной путь**: переработайте сырую нефть в [нефтеперерабатывающем заводе](@oritech:refinery_block),
чтобы получить нафту. Обработайте нафту с песком в центрифуге и получите полимерную смолу,
которую можно переплавить в пластиковые листы. Этот способ требует более сложной подготовки, но даёт больше пластика.

Пластик используется в деталях машин высокого уровня и продвинутых компонентах автоматизации.
