Литейный цех специализируется на создании всех сплавов, необходимых для 
механизмов Oritech. 
Некоторые из них можно создать вручную, но это потребует 
значительно больше ресурсов, чем применение литейного цеха.

Как только подача энергии и руды стабилизируется, литейный цех станет эффективным способом получать сплавы для развития: сталь, электрум, адамант, биосталь, энергит и другие.

Если вы всё ещё создаёте сплавы вручную, обычно именно этот механизм окупается быстрее всего.
