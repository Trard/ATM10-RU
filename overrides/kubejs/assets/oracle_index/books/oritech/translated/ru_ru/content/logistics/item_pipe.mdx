Для предметной логистики в Oritech предусмотрены предметные трубы и блоки предметных фильтров. Трубы соединяются друг с другом и с соседними инвентарями.

В отличие от других труб, у предметных труб нет собственного инвентаря. Поэтому другие блоки, например воронки, не могут самостоятельно
помещать предметы в сеть. Вместо этого предметную трубу можно настроить на извлечение из соседнего инвентаря.

## Варианты
*   **Обычная**: базовая труба.
*   **Каркасная**: вариант размером с полный блок.
*   **Прозрачная**: показывает движущиеся внутри предметы. Работает, только если весь путь состоит из прозрачных труб.
*   **Воздуховод**: вариант с другим внешним видом. Воздуховоды соединяются только с другими трубами, но не напрямую с механизмами.

Чтобы переключить режим извлечения, щёлкните ПКМ по участку трубы, соединённому с блоком, из которого нужно извлекать предметы.
Извлечение включится, только если труба подключена к поддерживающему его блоку. Каждое соединение трубы переключается независимо.
Трубным ключом можно отключить соединения с отдельных сторон.

Извлечённые предметы направляются в **ближайший** доступный инвентарь дальше по сети с учётом расстояния в мире.

<Callout variant="warning">
    Трубы всегда извлекают предметы из первой непустой ячейки инвентаря.
    Если предмет невозможно поместить ни в один инвентарь сети, он заблокирует дальнейшее извлечение из этого инвентаря.

    В трубу можно установить мотор, щёлкнув по ней ПКМ. Тогда извлекающая труба сможет забирать предметы из всех ячеек. По умолчанию эта возможность отключена ради производительности.
</Callout>
