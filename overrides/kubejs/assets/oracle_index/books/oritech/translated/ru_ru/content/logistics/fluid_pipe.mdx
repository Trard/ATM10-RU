Перемещает жидкости между механизмами и резервуарами. Стандартная скорость передачи — 0.5 ведра каждые 3 такта. У жидкостных труб нет внутреннего хранилища.

## Использование
Подсоедините трубы к любому блоку, способному работать с жидкостями. Щёлкните ПКМ по нужной части трубы, чтобы переключить извлечение. Ключ для этого не требуется.
Однако с помощью ключа можно отключать соединения труб.

## Варианты
*   **Обычная**: базовая модель трубы.
*   **Каркасная**: вариант в виде сплошного блока для встраивания в стены.
*   **Воздуховод**: вариант с другим внешним видом. Воздуховоды соединяются только с другими трубами, но не напрямую с механизмами.
