Потолочный светильник — блок для освещения промышленных помещений.
Он ярко освещает большую площадь.

Существует два варианта:
*   **Накладной**: устанавливается непосредственно на грань блока.
*   **Подвесной**: крепится к цепи для использования с высокими потолками.

Светильник нельзя выключить.
