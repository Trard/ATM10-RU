Экстрактор коренной породы — крупный механизм
для добычи ресурсов из-под слоя коренной породы. 

<center>
<ModAsset location="oritech:area/bedrock_extraction" width={800} />
</center>

Он работает только при размещении непосредственно над 
[ресурсными узлами](@oritech:resource_node_redstone).

---

**Добыча ресурсов из-под коренной породы**

Экстрактор сканирует область 3x3 под собой и добывает из первых 
видимых рудных узлов на глубине до трёх блоков. 
При нажатии ПКМ механизм подсвечивает выбранные ресурсные 
узлы под ним.

Из-за высокого энергопотребления его нельзя питать через 
обычные кабели: энергию должны передавать 
[эндерические лазеры](@oritech:laser_arm_block).

Ресурсные узлы — бесконечные источники материалов, и экстрактор 
никогда их не истощит.

**Подробности работы**

В каждом успешном цикле экстрактор случайным образом выбирает один блок 
из области 3x3 под собой.
Не все блоки области обязаны быть рудными узлами, но для максимального 
выхода постарайтесь разместить экстрактор там, где таких узлов 
больше всего.
