Ядра механизмов определяют качество мультиблочных механизмов Oritech. Более совершенные ядра не ускоряют механизм автоматически. Их основное назначение — увеличить число поддерживаемых слоёв расширителей и подключённых дополнений.

**Создание**
- Ядра создаются по уровням, и каждый следующий уровень повышает предел качества.
- Для уровня 1 нужны доски и верстак.
- Для уровня 2 нужны медь или железо с лазуритом.
- Для уровня 3 нужны [углеродные волокна](@oritech:carbon_fibre_strands) или [никель](@oritech:nickel_ingot) с редстоуном.
- Для уровня 4 нужны [блоки обшивки механизмов](@oritech:machine_plating_block) и [эндерическая смесь](@oritech:enderic_compound).
- Для уровня 5 нужны [адамант](@oritech:adamant_ingot) и [продвинутые вычислительные модули](@oritech:advanced_computing_engine).
- Для уровня 6 нужны [дуратий](@oritech:duratium_ingot) и [сомнительные контейнеры](@oritech:dubios_container).
- Для уровня 7 нужны [прометий](@oritech:promethium_ingot) и [сверхпроводники](@oritech:superconductor).

**Применение**
- При нажатии ПКМ мультиблочный механизм подсвечивает места для необходимых ядер.
- Можно также нажать ПКМ по механизму, держа ядро в руке: если нужное место свободно, следующее подходящее ядро установится автоматически.
- Итоговое качество механизма определяет глубину расширителей и масштабирование дополнений, а не скорость обработки как таковую.
