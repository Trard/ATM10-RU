Реакторы можно проектировать по своему усмотрению. Как правило, двойные и четверные стержни эффективнее расходуют топливо, поскольку вырабатывают больше RF с каждой таблетки, но при этом
охлаждать их гораздо сложнее.

Можно использовать активное охлаждение поглотителями тепла или пассивное охлаждение одними теплоотводами. Окружённый активными компонентами со всех сторон одиночный поглотитель
может забирать до 16 * 4 = 64 единиц тепла за такт, но для работы ему необходим лёд. Лёд можно получать из воды в промышленном охладителе.

Одиночный теплоотвод рассеивает тепло в зависимости от самого горячего соседнего блока. При 1000 C он отведёт 14 единиц тепла, а при 0 C — всего 4. В зависимости от
задачи стоит либо распределять тепло по множеству теплоотводов с помощью распределителей тепла, либо окружить несколько поглотителей тепловыми трубами.

Конструкции реакторов могут различаться. Небольшого реактора может быть достаточно для выработки энергии в начале и середине игры, тогда как на позднем этапе могут понадобиться огромные реакторы.
При испытании конструкций рекомендуется использовать малые таблетки: если реактор начнёт перегреваться, его удастся быстрее отключить.
