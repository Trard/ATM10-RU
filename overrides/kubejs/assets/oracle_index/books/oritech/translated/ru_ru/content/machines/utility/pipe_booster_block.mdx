Усилитель труб — улучшение для логистических сетей с высокой 
пропускной способностью. 
Если поставить его рядом с точкой извлечения трубы и подать RF, 
он значительно увеличит скорость извлечения предметов и жидкостей 
из подключённого инвентаря.

<center>
<ModAsset location="oritech:area/item_pipes_boosted" width={512} />
</center>

---

**Производительность извлечения**

- **Предметные трубы**: ускоряет извлечение до одной полной стопки 
за такт.
- **Жидкостные трубы**: повышает пропускную способность до 50 вёдер за такт.

<Callout variant="info">
    Для работы усилитель должен быть направлен непосредственно на **извлекающий** блок трубы 
    — место её соединения с механизмом.
</Callout>
