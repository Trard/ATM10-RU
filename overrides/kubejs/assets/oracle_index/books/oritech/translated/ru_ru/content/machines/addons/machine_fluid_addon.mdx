---
title: Жидкостное дополнение
id: oritech:machine_fluid_addon
type: block
---

Жидкостное дополнение позволяет обрабатывать жидкости механизмам,
которые обычно работают только с предметами.

Оно необходимо для следующих операций:
- Чтобы [центрифуга](@oritech:centrifuge_block) могла обрабатывать и
разделять жидкости.
- Чтобы [порт дронов](@oritech:drone_port_block) мог перевозить жидкости.

<Callout variant="info">
    После подключения механизм получает хранилище жидкости, а в интерфейсе
    появляются соответствующие жидкостные ячейки.
</Callout>
