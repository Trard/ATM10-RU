Целеуказатель — инструмент, задающий механизмам направление.
С его помощью можно сохранить позицию, а затем
передать её механизму.

### Использование

1. **Сохранение позиции**: щёлкните ПКМ по блоку, чтобы сохранить
   его координаты.
2. **Передача механизму**: удерживая целеуказатель, щёлкните по механизму
   ПКМ с зажатым Shift, чтобы назначить ему новую цель.

### Механизмы

Целеуказатель требуется следующим механизмам:

- [Лазерный манипулятор](@oritech:laser_arm_block): задаёт направление
  выстрела лазера.
- [Порт дронов](@oritech:drone_port_block): задаёт место назначения
  для дронов.
- [Опора ЛЭП](@oritech:power_pole_block): соединяет опоры ЛЭП
  друг с другом.

### Охотничьи расширения

Если на [лазерном манипуляторе](@oritech:laser_arm_block) установлены **охотничьи расширения**,
целеуказатель позволяет изменить тип его целей, например
назначить мобов или игроков.

<Callout variant="info">
    Сохранённые координаты отображаются во всплывающей подсказке предмета.
</Callout>
