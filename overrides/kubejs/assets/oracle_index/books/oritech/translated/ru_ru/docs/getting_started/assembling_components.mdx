Следующим важным шагом станет постройка [сборщика](@oritech:assembler_block) и [центрифуги](@oritech:centrifuge_block).

Сборщик производит многие компоненты эффективнее ручного изготовления, а некоторые детали без него вовсе невозможно изготовить должным образом.

Центрифуга преобразует ресурсы, необходимые для дальнейшего технологического развития: перерабатывает рудные глыбы, производит углеродное волокно, а после установки нужного дополнения работает и с жидкостями.

Оба механизма требуют энергии RF и становятся гораздо полезнее после знакомства с [дополнениями]($ADDON_CONCEPTS).
