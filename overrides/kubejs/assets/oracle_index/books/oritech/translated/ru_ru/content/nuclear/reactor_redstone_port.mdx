Сигнал редстоуна на редстоун-порт прекращает приём нового топлива.

Все уже горящие топливные элементы должны полностью выгореть, прежде чем реактор окончательно остановится
после подачи сигнала редстоуна на порт.

Порт также может передавать данные через компаратор. У него есть 3 режима:

*   **Температура**: сила сигнала зависит от температуры самого горячего компонента относительно максимальной температуры реактора
*   **Количество активных стержней**: показывает число стержней, в которых горит топливо (то есть фактическое количество активных стержней в каждом слое; двойные и четырёхкратные стержни считаются за один)
*   **Энергия**: измеряет текущий запас RF

Чтобы переключить режим, щёлкните ПКМ по порту.

Подробное описание механики реактора приведено в [руководстве по ядерному реактору]($reactor/introduction).
