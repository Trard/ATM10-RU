Трубный ключ — основной инструмент для управления заводской
логистикой. Он работает со всеми видами труб и кабелей
из мода.

### Трубы

Ключ позволяет настраивать трубопроводные сети:
- **Переключение**: щёлкните по концу трубы в месте её подключения,
  чтобы включить или отключить соединение.
- **Быстрый сбор**: щёлкните ПКМ по трубе с зажатым Shift,
  чтобы мгновенно её подобрать.

С помощью ключа можно **скользить по проводам** между
[опорами ЛЭП](@oritech:power_pole_block). Просто щёлкните
ПКМ по проводу, чтобы быстро добраться до другого конца.

Скольжение по проводам позволяет быстро перемещаться,
не расходуя энергию.
