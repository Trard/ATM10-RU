Органический прекурсор промышленного пластика, изготовленный из биологического сырья.

**Создание**
- **Центрифуга**: извлекается с помощью воды из [уплотнённой пшеницы](@oritech:packed_wheat), [твёрдого биотоплива](@oritech:solid_biofuel) 
или блоков биомассы.

**Применение**
Служит основой для пластика, специализированных жидкостей и биологических аугментаций.
