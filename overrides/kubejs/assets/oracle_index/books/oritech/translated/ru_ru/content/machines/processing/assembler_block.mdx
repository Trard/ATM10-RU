Сборщик оснащён сеткой создания 2x2 и автоматически создаёт предметы, 
пока у него есть энергия, предметы во входных ячейках 
и место для готового продукта в выходной ячейке.

Некоторые компоненты механизмов можно создать без сборщика,
но на это уйдёт значительно больше ресурсов.

Порядок компонентов во входных ячейках не имеет значения. Если механизму нужны два одинаковых предмета, он может взять оба
из одной ячейки.

## Автоматизация

Для точного распределения предметов можно использовать дополнение удалённого доступа к инвентарю. Кроме того,
у сборщика есть разные режимы ввода. Режимы «Равномерно» и «По сторонам» могут заметно упростить автоматизацию некоторых систем.

Автоматизация также возможна через AE2 / RS2. Поставщики шаблонов работают со сборщиком без дополнительной настройки.


## Эффективность

Сборщик — рекомендуемый способ производства сложных
компонентов, например [двигателей](@oritech:motor) или
[магнитных катушек](@oritech:magnetic_coil).
Создать эти компоненты вручную можно, но это потребует больше 
ресурсов, чем применение сборщика.
