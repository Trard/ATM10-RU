Направляющие кольца задают путь движения частиц в ускорителе.

Щелчок ПКМ по кольцу добавляет с одной стороны поворот на 45 градусов. На заданном направляющими пути частицы
должно находиться следующее кольцо. Допустимое расстояние между направляющими блоками увеличивается вместе со скоростью.

### Редстоун-переключатели

При подаче сигнала редстоуна на изогнутую направляющую она становится блоком-переключателем.
При наличии сигнала частицы движутся прямо, а без сигнала направляются по исходной кривой.

Подробное описание механики ускорения частиц приведено в [руководстве по ускорителю частиц]($particle_accelerator).
