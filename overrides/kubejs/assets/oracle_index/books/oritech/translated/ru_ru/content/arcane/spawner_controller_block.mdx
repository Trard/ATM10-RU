Контроллер спавнера управляет автоматизированной системой создания мобов. Разместив его
над [спаунерной клеткой](@oritech:spawner_cage_block), можно создавать мобов определённого вида.

<Callout variant="warning">
    *Oritech Inc* не несёт ответственности за экзистенциальные кризисы мобов, усомнившихся
    в своём жизненном предназначении, а также за любые этические сомнения, которые может вызвать у вас промышленный сбор душ.
</Callout>

## Настройка

Вид моба определяется первой сущностью, прошедшей по контроллеру. Изменить его
можно только после разрушения и повторной установки контроллера. Когда вид моба
назначен, контроллер подсвечивает необходимый размер спаунерной клетки
под собой.

## Работа

Контроллер собирает души погибших поблизости существ и расходует их для создания
назначенного моба.

- **Стоимость в душах**: число душ, необходимое для одного создания, рассчитывается
  по здоровью моба, а именно по квадратному корню его максимального запаса здоровья.
- **Радиус создания**: контроллер ищет подходящую поверхность для появления
  в небольшом радиусе 4 блоков вокруг себя.
- **Управление красным камнем**: сигнал красного камня отключает контроллер
  и прекращает все операции создания.

Щелчок ПКМ по контроллеру выводит сведения о его текущем состоянии,
включая назначенного моба и имеющееся число душ.

<Callout variant="info">
    Спавнеру нельзя назначить виды мобов из тега `oritech:spawner_blacklist`.
</Callout>
