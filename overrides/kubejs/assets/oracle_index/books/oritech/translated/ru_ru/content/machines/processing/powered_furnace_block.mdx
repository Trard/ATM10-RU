Электропечь — современная замена традиционной 
каменной печи. Она использует энергию RF, переплавляя предметы с гораздо большей 
скоростью и эффективностью. Электропечь вдвое быстрее обычной.


Это один из лучших механизмов для удобства, который стоит построить после первого генератора: он полностью избавляет 
от необходимости вручную подкладывать топливо для переплавки.
