# Исследования и разработки

Для начала войдите внутрь собранного **центра кибернетической аугментации**. 
Откроется интерфейс исследований, где можно просматривать и запускать проекты. 
Для каждой аугментации нужны определённые энергия и ресурсы из вашего инвентаря или 
внутреннего хранилища механизма, доступного через интерфейс.

Для многих высокоуровневых улучшений необходимы предыдущие исследования, как показано в технологическом дереве.

Центр служит узлом для **исследовательских станций**, построенных как мультиблочные расширения. Основной блок поддерживает 
до **трёх станций**, позволяя вести параллельную обработку.
*   Для каждой станции нужны **3 ядра механизма**.
*   Станция выполняет одну активную исследовательскую задачу за раз.

# Установка и управление

После завершения исследования аугментацию можно установить. Процедура требует однократной затраты ресурсов,
чтобы навсегда объединить технологию с телом игрока.

Установленные аугментации можно загрузить в механизм функцией **«Импорт»** 
(кнопка в нижнем левом углу интерфейса).

**Управление аугментациями**:
Улучшения задуманы как постоянные: им не требуется обслуживание или непрерывная подача энергии. 
Однако мешающую способность, например **зрение руды** или **гиперскорость**, можно в любой момент отключить.

*   **Меню переключения**: удерживайте клавишу аугментаций (**[G]** по умолчанию), чтобы открыть круговой интерфейс. Наведите указатель на нужную 
аугментацию и отпустите клавишу, чтобы изменить её состояние.
*   **Удаление**: хотя аугментации рассчитаны на постоянное использование, при необходимости их можно удалить. 
Учтите, что ресурсы, потраченные на установку, не возвращаются.

**Информация для разработчиков сборок**

Аугментации Oritech полностью управляются данными и настраиваются, что позволяет глубоко изменять их с помощью датапаков.

*   **Аугментации-модификаторы**: изменяют атрибуты существа (например, скорость, дальность взаимодействия, здоровье).
*   **Аугментации-эффекты**: накладывают эффекты состояния, подобные зельям.
*   **Пользовательские аугментации**: реализуют уникальную логику (например, зрение руды). На них можно ссылаться в датапаках, но для самой логики требуется Java-мод.

Существующие аугментации можно изменять или отключать, а совершенно новые — определять через JSON.
*   **Пример определения**: [аугментация урона от атаки (GitHub)](https://github.com/Rearth/Oritech/blob/1.21/fabric/src/main/generated/data/oritech/recipe/augment/attackdamage.json)
*   **Расположение текстуры**: `oritech/textures/gui/augment`

Не забудьте добавить строки перевода для всех пользовательских дополнений.
