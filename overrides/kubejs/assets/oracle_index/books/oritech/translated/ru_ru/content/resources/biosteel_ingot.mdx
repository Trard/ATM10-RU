Биосталь — более экологичная альтернатива стали. Этот сплав среднего уровня применяется для создания [улучшений]($ADDON_CONCEPTS), [датчиков](@oritech:accelerator_sensor)
и других компонентов.

Её можно создать в [литейной](@oritech:foundry_block) из железа и [биомассы](@oritech:biomass).
