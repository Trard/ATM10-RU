---
title: Многоблочные конструкции
icon: oritech:item/machine_core_6
---

Для работы некоторых механизмов требуются дополнительные ядра механизмов. Их нужно размещать в определённых местах относительно самого механизма.
Необходимое число ядер указано во всплывающей подсказке механизма. Одно ядро нельзя использовать сразу для нескольких механизмов.

<Callout variant="info">
    Более качественные ядра не ускоряют работу механизмов. Они влияют только на число доступных слоёв расширителей механизмов.
</Callout>

Чтобы начать строительство многоблочной конструкции, сначала установите сам механизм.

После щелчка ПКМ по механизму на несколько секунд подсветятся все места, в которых должны находиться ядра.
Затем установите ядра в эти места. Также можно щёлкнуть ПКМ по механизму, держа ядро в руке: следующее ядро установится автоматически.
Это работает только тогда, когда нужное место ничем не занято. Если путь преграждает другой блок, вместо места установки подсветится препятствие.

Каждое ядро механизма обладает определённым качеством. Чем лучше используемые ядра, тем выше общее качество механизма.

Чтобы узнать итоговое качество механизма, наведите указатель на его значок в левом верхнем углу интерфейса.
Само по себе качество не влияет на работу механизма, но определяет, сколько дополнений к нему можно подключить.
Если вы не собираетесь устанавливать дополнения, можно использовать самые дешёвые ядра.
