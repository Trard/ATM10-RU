---
title: Контроллер ускорителя
id: oritech:accelerator_controller
type: block
---

Контроллер ускорителя частиц служит точкой ввода частиц. Помещённые в этот блок предметы превращаются в частицы.
Результаты столкновений можно забрать из выходного слота.

Прямое [направляющее кольцо](@oritech:accelerator_ring) необходимо установить сразу за контроллером, повернув в сторону
так, чтобы изображения правильно совместились. В контроллер можно поместить любой предмет и использовать его как частицу.

После ввода частица движется по маршруту, заданному направляющими кольцами.

Подробное описание механики ускорения частиц приведено в [руководстве по ускорителю частиц]($particle_accelerator).
