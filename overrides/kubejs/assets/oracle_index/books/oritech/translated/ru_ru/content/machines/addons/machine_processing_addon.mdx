Дополнение «Вспомогательная камера обработки» позволяет механизму одновременно
обрабатывать несколько предметов или рецептов.
Каждая установленная камера добавляет одну ячейку обработки, поэтому
механизм может выполнить два рецепта за время, которое обычно
занимает один.

Подходит для всех механизмов обработки по рецептам (например, измельчителя, центрифуги, сборщика и т. п.).

Каждое дополнение увеличивает расход энергии на 50%, делая механизм
более энергоёмким, чем обычные машины.
Оно лучше всего подходит для массовой обработки, где пропускная способность
важнее эффективности.

---

**Параллельная обработка**

В каждом цикле механизм пытается запустить новый рецепт в каждой
доступной камере.
С тремя дополнениями камер он может одновременно обрабатывать четыре предмета.
Для очень длительных рецептов это гораздо эффективнее дополнений скорости.
