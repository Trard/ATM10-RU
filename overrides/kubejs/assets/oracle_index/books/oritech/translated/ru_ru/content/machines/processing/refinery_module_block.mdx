Модули камеры НПЗ — компоненты расширения для 
[промышленного НПЗ](@oritech:refinery_block). 
Поверх одного блока НПЗ можно установить до двух модулей, 
чтобы открыть дополнительные каналы вывода жидкостей.

---

**Управление несколькими выходами**

Каждый модуль служит отдельным резервуаром для вторичных и третичных 
жидких продуктов переработки. 
Жидкости нужно отводить непосредственно из блоков модулей, а не 
из основания НПЗ. 
Этим модулям также требуются собственные 
[ядра механизмов]($multiblocks), чтобы стать частью мультиблочной
конструкции.
