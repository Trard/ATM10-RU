Опоры электропередачи передают энергию на большие расстояния.
Обычно их строят на возвышенных площадках; соединяться они могут только с другими опорами электропередачи.
<center>
<ModAsset location="oritech:area/power_pole" width={512} />
</center>

Чтобы соединить опоры, возьмите [целеуказатель](@oritech:target_designator), щёлкните с зажатым Shift сначала по первой,
а затем по второй. Одна опора может соединяться с любым числом других опор.
Все взаимосвязанные опоры обмениваются энергией, позволяя создавать крупные сети.

Энергию можно вводить и выводить через любую опору в объединённой сети.
Ввод выполняется через зелёный порт, а вывод — через красный.
Максимальная скорость передачи по сети ограничена 1M RF/t.

<Callout variant="info">
    Опоры электропередачи предназначены только для передачи энергии на большие расстояния, но их дальность не бесконечна.
    Для соединения их нужно строить на расстоянии не менее 50 и не более 1000 блоков друг от друга.
</Callout>

С помощью [трубного ключа](@oritech:wrench) можно скользить по проводам между опорами.
Для этого щёлкните по проводу, держа ключ в руке.
