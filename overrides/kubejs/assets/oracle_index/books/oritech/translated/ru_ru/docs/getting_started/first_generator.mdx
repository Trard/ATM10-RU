Создайте **базовый генератор** — ваш первый полноценный источник RF.

<CraftingRecipe
    slots={[
        'oritech:nickel_ingot',
        'oritech:nickel_ingot',
        'oritech:nickel_ingot',
        'oritech:nickel_ingot',
        'minecraft:copper_ingot',
        'oritech:nickel_ingot',
        'oritech:magnetic_coil',
        'minecraft:furnace',
        'oritech:magnetic_coil'
    ]}
    result="oritech:basic_generator_block"
    count={1}
/>

Он сжигает обычное печное топливо и вырабатывает **32 RF/t** — этого достаточно для запуска первых перерабатывающих механизмов.

Одного генератора хватит для начальной мастерской, но вскоре его станет недостаточно. Смело стройте несколько, пока развиваетесь до более мощных генераторов и автоматизации.

После запуска генератора удобным первым улучшением станет [электропечь](@oritech:powered_furnace_block).
