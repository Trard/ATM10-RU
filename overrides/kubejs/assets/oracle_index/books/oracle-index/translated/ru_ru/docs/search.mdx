---
title: Поиск
---

В Oracle Index предусмотрен умный поиск. Чтобы открыть его, нажмите [CTRL + ORACLE_HOTKEY] или отдельную клавишу поиска,
которая по умолчанию не назначена. Небольшой значок поиска также доступен при просмотре статьи вики.

<Callout variant="info">
    Поиск также умеет вычислять математические выражения!
</Callout>

При первом открытии поиска индексация доступных страниц может занять несколько секунд. Полноценный семантический поиск
работает на основе машинного обучения, поэтому точные ключевые слова не обязательны: можно вводить целые предложения, и
система покажет подходящие материалы, даже если слова не совпадают буквально.

## Технические подробности
Oracle Index создаёт эмбеддинги для всех страниц, предварительно разбитых на фрагменты. Небольшая модель преобразования
предложений (all-MiniLm-L6-V2-q) генерирует эмбеддинги для каждого фрагмента и поискового запроса. Векторы хранятся в
памяти, а вектор запроса сравнивается с эмбеддингами фрагментов вики. Пользователю показываются N ближайших результатов.

Для этого используется библиотека Langchain4j на базе DJL Framework. Размер модели эмбеддингов — около 15 МБ.
