---
title: Руководство пользователя
---

Oracle Index — клиентский мод внутриигровой документации, предназначенный для просмотра материалов
[moddedmc.wiki](https://moddedmc.wiki/) прямо в игре.

Разработчики могут включить в свои моды вики и показывать их в игре с помощью Oracle Index. Чтобы открыть экран Oracle
Index, нажмите назначенную клавишу вики, по умолчанию [H]. Специальная книга или другой предмет не нужны. При закрытии
экрана мод запомнит место, на котором вы остановились.

Документацию мода можно просматривать, только если сам мод установлен, а его разработчик включил материалы moddedmc.wiki
в состав вики Oracle Index.

## Переключение модов
Слева находится панель навигации по выбранному моду. Чтобы переключиться на другой мод, щёлкните по заголовку над панелью.
Откроется выпадающий список, в котором можно выбрать нужный мод.

## Ссылки у предметов
Разработчики могут связывать игровые предметы со страницами вики. Если для предмета существует страница, в его подсказке
появится дополнительная строка. Увидев её, удерживайте [ALT], чтобы открыть соответствующую статью.

## Язык
Oracle Index автоматически показывает доступный перевод как содержимого страниц, так и панели навигации. Поиск пока не
поддерживает запросы по переведённому тексту, но найденные результаты откроются на выбранном языке, если перевод существует.
