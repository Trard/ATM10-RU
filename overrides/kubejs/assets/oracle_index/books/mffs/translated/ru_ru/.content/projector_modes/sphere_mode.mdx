# Режим сферы

По умолчанию режим сферы заставляет [проектор](@mffs:projector) создавать силовое поле в форме сферы толщиной ровно 1 блок.

Каждый [](mffs:scale_module) увеличивает размер силового поля на 1 блок.

<PrefabObtaining />

## Настройка поля

Каждый [модуль масштаба](mffs:scale_module), добавленный в слот со стрелкой направления, дополнительно увеличивает радиус
силового поля на 1 блок.
