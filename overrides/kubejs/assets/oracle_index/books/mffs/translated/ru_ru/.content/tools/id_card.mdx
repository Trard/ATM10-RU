# Идентификационная карта

Идентификационная карта MFFS используется вместе с [](@mffs:biometric_identifier) для управления правами и привилегиями
игроков.

<PrefabObtaining />

## Использование

Перед использованием идентификационную карту необходимо назначить игроку. Чтобы назначить её себе, щёлкните правой кнопкой
мыши, держа карту и присев. Таким же щелчком по другому игроку можно назначить карту ему. Используйте карту ещё раз, чтобы
удалить сохранённую личность.
