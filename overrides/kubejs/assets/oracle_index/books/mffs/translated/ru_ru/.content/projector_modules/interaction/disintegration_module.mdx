# Модуль дезинтеграции

Модуль дезинтеграции используется в [](@mffs:projector), чтобы изменить воздействие силового поля на окружающий мир.
Если поместить его в слоты матрицы проектора, создаваемое поле будет разрушать препятствующие ему блоки. Разрушенные блоки
выпадают в виде предметов, которые можно подобрать.

<PrefabObtaining />

## Использование

Модуль дезинтеграции совместим со всеми режимами проектора и может использоваться для обратного эффекта
[](mffs:stabilization_module). Установка [модулей скорости](@mffs:speed_module) позволяет дезинтегрировать несколько
блоков одновременно. Кроме того, его можно совместить с [](@mffs:collection_module), чтобы автоматически собирать
разрушенные блоки.
