# Модуль вращения

Модуль вращения устанавливается в слоты поля [](@mffs:projector), чтобы поворачивать проецируемое поле.

Для вращения силового поля вокруг оси X, Y или Z поместите модули вращения в соответствующий этой оси слот.

- ВОСТОК, ЗАПАД — изменяют рыскание
- ВВЕРХ, ВНИЗ — изменяют тангаж
- ЮГ, СЕВЕР — изменяют крен
