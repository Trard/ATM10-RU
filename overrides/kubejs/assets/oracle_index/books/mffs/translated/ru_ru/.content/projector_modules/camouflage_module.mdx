# Модуль маскировки

Модуль маскировки используется в [](@mffs:projector), чтобы изменять внешний вид силового поля. С установленным модулем
поле можно замаскировать под обычные блоки — например, под стену из [камня](@stone). Модуль маскировки совместим со всеми
режимами проектора.

<PrefabObtaining />

## Использование

Эта функция проектора помогает скрывать объекты от других игроков или маскировать вход на секретную базу. Выберите блок
для маскировки и поместите его в другой свободный слот левой матрицы предметов проектора — туда же, где находится модуль
маскировки. Затем включите проектор обычным способом.
