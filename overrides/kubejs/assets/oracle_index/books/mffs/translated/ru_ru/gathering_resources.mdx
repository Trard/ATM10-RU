# Сбор ресурсов

Первый шаг к созданию силовых полей — поиск основных ресурсов.

Компоненты MFFS в основном изготавливаются из [стальных слитков](@mffs:steel_ingot), которые получаются в два простых
этапа. Сначала создайте [](@mffs:steel_compound), а затем переплавьте её в слитки.

Это один из самых распространённых материалов MFFS. Он используется для изготовления основных компонентов, таких как
[](@mffs:focus_matrix) и пустая карта, а также машин силового поля.
