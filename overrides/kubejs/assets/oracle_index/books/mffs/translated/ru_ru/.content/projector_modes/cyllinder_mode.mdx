# Режим цилиндра

По умолчанию режим цилиндра заставляет [проектор](@mffs:projector) создавать силовое поле в форме цилиндра толщиной ровно
1 блок. Каждый [](mffs:scale_module) увеличивает размер поля на 1 блок в выбранном направлении.

<PrefabObtaining />

## Настройка поля

Если поместить [](mffs:scale_module) в слот со стрелкой направления, поле увеличится на 1 блок только в эту сторону.
Например, чтобы увеличить высоту поля на 1 блок, добавьте модуль масштаба в слот со стрелкой, направленной в левый или
правый верхний угол интерфейса.
