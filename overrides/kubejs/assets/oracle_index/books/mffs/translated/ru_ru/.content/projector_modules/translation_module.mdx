# Модуль смещения

Модуль смещения устанавливается в слоты поля [](@mffs:projector), чтобы сдвигать положение проецируемого поля.

Чтобы переместить силовое поле в нужную сторону, поместите модули смещения в соответствующий слот направления. Каждый
модуль сдвигает поле на 1 блок.
