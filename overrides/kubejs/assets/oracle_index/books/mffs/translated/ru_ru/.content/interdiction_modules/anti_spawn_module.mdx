# Модуль подавления появления

Модуль подавления появления — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

С установленным модулем матрица предотвращает появление враждебных и мирных существ в своей области действия.

Если у игрока есть яйцо призыва, он сможет создать существо внутри защищённой области, стоя непосредственно за границей
действия матрицы.
