# Карта частоты

Карта частоты может хранить, запоминать и генерировать частоты для взаимодействия с машинами. Чтобы записать на неё
частоту, поместите карту в частотный слот машины. Использование карты на любой машине установит ей записанную частоту.
Чтобы сгенерировать случайную частоту, щёлкните правой кнопкой мыши, держа карту и присев.
