# Модуль блокировки изменения блоков

Модуль блокировки изменения блоков — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

Он позволяет матрице запрещать игрокам размещать и разрушать блоки. Если игрок попытается изменить блок в области действия
матрицы запрета, она сообщит об отсутствии разрешения и отменит совершённое изменение.
