# Модуль против мирных существ

Модуль против мирных существ — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

С установленным модулем матрица автоматически обнаруживает мирных существ, например овец, коров и жителей, попавших в
область сканирования, и почти мгновенно убивает их. Игроки и враждебные мобы не получают урона.
