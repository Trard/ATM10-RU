# Модуль электрошока

Установка модуля электрошока в [](@mffs:projector) электризует силовое поле. Коснувшийся такого поля игрок или существо
получает удар током и урон. Каждый добавленный в проектор модуль увеличивает наносимый урон на половину сердца.
