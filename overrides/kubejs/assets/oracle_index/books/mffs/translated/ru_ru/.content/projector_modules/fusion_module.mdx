# Модуль слияния полей

Модуль слияния полей устанавливается в слоты матрицы [](@mffs:projector), чтобы объединить два или несколько
проецируемых полей.

Модуль отсекает все проецируемые блоки, перекрывающиеся с другим силовым полем. Несколько силовых полей с таким модулем
бесшовно объединяются в одно.
