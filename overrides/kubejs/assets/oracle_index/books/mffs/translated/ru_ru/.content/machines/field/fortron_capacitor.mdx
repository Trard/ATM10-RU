# Конденсатор фортрона

Конденсатор фортрона хранит энергию и управляет ею для машин MFFS. Он собирает []($fortron), выработанный
[извлекателями энергии](@mffs:coercion_deriver), и передаёт его другим машинам, которым []($fortron) нужен для работы,
фактически действуя как центральный узел.

<PrefabObtaining />

## Использование

Установите конденсатор и задайте используемую частоту. По умолчанию используется частота 0, но её можно изменить одним из
способов:

- Щёлкнуть по конденсатору правой кнопкой мыши и ввести нужную частоту в интерфейсе
- Щёлкнуть по конденсатору правой кнопкой мыши в приседе, держа [](@mffs:frequency_card)

Активируйте конденсатор сигналом редстоуна. После включения его цвет сменится с красного на синий, и начнётся передача
фортрона между устройствами MFFS на той же частоте в пределах дальности, по умолчанию равной 15 блокам.

## Улучшения

Возможности конденсатора фортрона можно расширить различными модулями:

- [](@mffs:scale_module): позволяет связываться с машинами MFFS на большем расстоянии; каждый модуль увеличивает стандартную
  дальность в 15 блоков ещё на 1 блок
- [](@mffs:speed_module): ускоряет передачу []($fortron) к машинам и от них; каждый модуль повышает скорость на 50 FE
- [](@mffs:capacity_module): увеличивает количество []($fortron), которое хранит конденсатор
