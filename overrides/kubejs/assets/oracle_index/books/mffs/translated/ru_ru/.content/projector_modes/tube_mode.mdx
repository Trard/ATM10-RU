# Режим трубы

По умолчанию режим трубы заставляет [проектор](@mffs:projector) создавать силовое поле в форме квадратной трубы, или
четырёхугольной призмы, толщиной ровно 1 блок. Поле состоит из четырёх сплошных сторон, параллельных горизонтальной
плоскости. Передняя и задняя стороны [проектора](@mffs:projector) соответствуют открытым торцам трубы силового поля.

<PrefabObtaining />

## Настройка поля

Если поместить [](mffs:scale_module) в слот со стрелкой направления, поле увеличится на 1 блок только в эту сторону.
Например, чтобы увеличить высоту поля на 1 блок, добавьте [](mffs:scale_module) в слот со стрелкой, направленной в левый
или правый верхний угол интерфейса.
