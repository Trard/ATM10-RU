# Фортрон

Фортрон — форма энергии, которую машины MFFS используют в качестве источника питания. Сначала его производит и хранит
[](@mffs:coercion_deriver), а затем [](@mffs:fortron_capacitor) передаёт его другим машинам.

Другой источник фортрона — доступная только в творческом режиме карта бесконечной энергии. Её можно поместить прямо в
[](@mffs:fortron_capacitor), в крайний левый слот предмета, чтобы получить бесконечный запас фортрона.

Фортрон может существовать в виде жидкости. Его можно выкачивать непосредственно из
[конденсатора](@mffs:fortron_capacitor) и перемещать так же, как [воду](@water) или [лаву](@lava).
