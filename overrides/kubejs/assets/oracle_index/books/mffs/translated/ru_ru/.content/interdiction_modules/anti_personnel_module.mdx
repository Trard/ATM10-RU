# Модуль против игроков

Модуль против игроков — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

С установленным модулем матрица автоматически обнаруживает неавторизованных игроков в области действия и почти мгновенно
убивает их.

Мирные и враждебные мобы не получают урона.
