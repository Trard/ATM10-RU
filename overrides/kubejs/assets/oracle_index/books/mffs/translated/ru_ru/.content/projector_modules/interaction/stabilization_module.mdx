# Модуль стабилизации

Модуль стабилизации используется в [](@mffs:projector), чтобы кристаллизовать поле в твёрдую форму. Вместо энергетического
барьера, исчезающего после отключения, проектор заменяет поле настоящими блоками, предоставленными игроком.

Таким образом модуль стабилизации создаёт точную физическую копию формы силового поля, которая остаётся после отключения
проектора. Поскольку поле строится из настоящих блоков, его прочность соответствует прочности этих блоков. Пока проектор
получает достаточно энергии и запасных блоков, он постоянно восстанавливает повреждённую структуру поля.

Стабилизация (перенос) расходует больше фортрона и выполняется медленнее обычного проецирования поля, но вместе с режимом
[](@mffs:custom_mode) возможные применения практически безграничны.

Например, можно создать сооружение, которое автоматически восстанавливается всякий раз, когда [крипер](@creeper) пытается
его взорвать. Установка [модулей скорости](@mffs:speed_module) позволяет стабилизировать несколько блоков одновременно.

## Использование

- Поставьте сундук с необходимыми для строительства поля блоками рядом с проектором силового поля с любой стороны.
- Вставьте модуль стабилизации поля в слоты матрицы проектора, настройте желаемую форму и включите проектор.
- Проектор расходует блоки из соседних сундуков в порядке их расположения. Если в сундуке лежат разные блоки, целевая
  структура также будет состоять из их смеси.

## Использование пользовательского режима

В отличие от других режимов проектора силового поля, предмет пользовательского режима сохраняет точные положение и тип
каждого проанализированного блока. Поэтому стабилизация с [](@mffs:custom_mode) работает иначе. Проектор не расходует
блоки по порядку и не переносит их в произвольные места, а берёт только те типы блоков, которые соответствуют исходному
шаблону.

Каждый блок размещается точно в соответствии со своим типом и положением. Если у проектора заканчиваются подходящие блоки,
необходимые для воспроизведения шаблона, он приостанавливается до пополнения запаса.
