# Модуль против враждебных существ

Модуль против враждебных существ — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

С установленным модулем матрица автоматически обнаруживает враждебных мобов, попавших в область сканирования, и почти
мгновенно убивает их.

Игроки и невраждебные существа, такие как жители и животные, не получают урона.
