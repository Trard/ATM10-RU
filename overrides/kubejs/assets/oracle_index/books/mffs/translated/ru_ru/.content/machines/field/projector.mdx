# Проектор силового поля

Проектор силового поля — основная машина семейства MFFS. Он использует энергию []($fortron), чтобы создавать в мире
силовые поля разных форм и размеров.

<PrefabObtaining />

## Использование

Для создания силового поля обеспечьте проектор []($fortron), связав его с ближайшим [](@mffs:fortron_capacitor).

Это можно сделать одним из способов:
- Щёлкнуть по проектору правой кнопкой мыши и ввести совпадающую частоту в интерфейсе
- Щёлкнуть по проектору правой кнопкой мыши в приседе, держа [](@mffs:frequency_card).

Создайте один из предметов режима проектора, чтобы выбрать форму силового поля. Щёлкните по проектору правой кнопкой мыши
и поместите предмет режима в центральный красный слот, окружённый направленными наружу стрелками.

Создайте несколько [](@mffs:scale_module) и поместите их в левую матрицу слотов интерфейса проектора. Каждый установленный
[](@mffs:scale_module) увеличивает радиус силового поля на один блок.

Число внизу интерфейса показывает, сколько []($fortron) нужно для поддержания поля выбранных размера и формы. Активируйте
проектор сигналом [редстоуна](@minecraft:redstone).

После включения цвет проектора сменится с красного на синий, и при достаточном запасе фортрона он начнёт создавать поле.

Чтобы проходить сквозь силовое поле, необходим [](@mffs:biometric_identifier).

## Улучшения

Проектор силового поля можно улучшить различными модулями.

Основные модули дают следующие эффекты:

- [](@mffs:scale_module): изменяет форму проецируемого силового поля
- [](@mffs:speed_module): позволяет проектору быстрее создавать силовое поле
- [](@mffs:capacity_module): увеличивает запас фортрона в проекторе
