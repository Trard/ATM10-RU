# Модуль свечения

Модуль свечения используется в [](@mffs:projector), чтобы освещать область вокруг поля.

Установка модулей свечения заставляет силовое поле излучать свет. Чем больше модулей добавлено (не более 64), тем ярче
поле, вплоть до уровня светокамня.
