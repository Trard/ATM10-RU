# Модуль блокировки доступа

Модуль блокировки доступа — дополнительный модуль для [](@mffs:interdiction_matrix). Он позволяет матрице запрещать
игроку взаимодействовать с блоком правой кнопкой мыши и открывать его интерфейс.

<PrefabObtaining />

## Эффект

Если неавторизованный игрок попытается щёлкнуть правой кнопкой мыши по блоку или машине в области действия матрицы запрета
с этим модулем, открыть интерфейс не получится. Блоками и машинами за пределами области действия можно пользоваться как
обычно.
