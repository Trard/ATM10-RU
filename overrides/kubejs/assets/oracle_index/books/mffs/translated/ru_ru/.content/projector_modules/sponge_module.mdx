# Модуль губки

Установка модуля губки в [](@mffs:projector) заставляет его постоянно обнаруживать и удалять любые жидкости внутри поля.
Скорость удаления можно повысить с помощью [модулей скорости](@mffs:speed_module). Для бесконечных жидкостей, таких как
[вода](@mffs:water), может потребоваться повышенная скорость.
