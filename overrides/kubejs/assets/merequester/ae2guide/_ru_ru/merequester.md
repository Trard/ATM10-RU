# ME-запросчик

<Row>
  <ItemImage id="requester" scale="3"/>
  <ItemImage id="requester_terminal" scale="3"/>
</Row>

Дополнение, позволяющее поддерживать заданный запас предметов и жидкостей в вашей
[ME-системе](ae2:getting-started.md#your-very-first-me-system).
<br/>

## Начало работы

Установите <ItemLink id="requester"/> и подключите его к сети. Это должна быть та же сеть, в которой находится ваша система
[автосоздания](ae2:ae2-mechanics/autocrafting.md), включая
[процессоры создания](ae2:ae2-mechanics/autocrafting.md#the-crafting-cpu) и <ItemLink id="ae2:pattern_provider"/>.

<RecipeFor id="requester"/>

Чтобы <ItemLink id="requester"/> работал, для поддерживаемых в запасе предметов или жидкостей должен существовать шаблон, а
их создание по обычному запросу игрока должно быть доступно. Блок автоматизирует лишь подачу запросов, само создание
выполняет [ME-система](ae2:getting-started.md#your-very-first-me-system).
<br/>

<FloatingImage src="assets/gui.png" align="right"/>

## Настройка

При первом открытии <ItemLink id="requester"/> отображается список настроек запросов. Количество слотов в одном блоке можно
изменить в конфигурации. Каждая строка интерфейса соответствует отдельному запросу.
<br/>

### Переключатель

Флажок слева включает и отключает запрос, настроенный в этой строке. Для отключённого запроса проверки не выполняются и
запас не поддерживается.<br/>
Так можно временно отключить отдельный запрос или запретить <ItemLink id="requester"/> создавать задания, пока вы изменяете
настройки строки.
<br/>

### Что хранить в запасе

Во втором столбце указывается, что нужно поддерживать в запасе. Это слоты-призраки, они не хранят настоящие предметы. При
перетаскивании предмета щёлкните правой кнопкой мыши, чтобы задать количество 1, или левой, чтобы использовать размер
перетаскиваемой стопки. Если перетащить ведро с жидкостью, правая кнопка выберет саму жидкость, а левая — ведро. Тип предмета
также можно быстро задать щелчком с Shift. Если нужного предмета нет в инвентаре, перетащите его из просмотрщика рецептов,
поддерживаемого Applied Energistics.
<br/>

### Размер запаса

Поле размера запаса определяет, сколько ресурса нужно хранить. Сначала укажите ресурс, а затем желаемое значение. Для
запросов не на предметы поле подстраивается под тип: например, `B` обозначает вёдра жидкости.<br/>
Когда текущий запас опускается ниже указанного количества, <ItemLink id="requester"/> запрашивает пополнение.
<br/>

### Размер партии

Следующее поле задаёт размер партии, которая будет запрошена, когда текущий запас опустится ниже значения из поля размера
запаса.<br/>
Это снижает нагрузку на [процессоры создания](ae2:ae2-mechanics/autocrafting.md#the-crafting-cpu) и участвующие машины:
вместо множества отдельных заданий всё количество запрашивается сразу.
<br/>

### Кнопка подтверждения

Чтобы применить изменения запроса, введите нужные значения размера запаса и партии, затем нажмите Enter или кнопку
подтверждения справа в текущей строке. Переход к другой строке вернёт значения к прежнему состоянию.
<br/>

### Полоса состояния

Полоса под полями ввода и кнопкой подтверждения показывает текущее состояние запроса.
<br clear="all" />
<br/>

## Состояния

Для каждого запроса на полосе состояния отображается одно из следующих состояний.
<br/>

### Серое — пусто

Текущая строка отключена или ресурс для запаса не задан.
<br/>

### Зелёное — ожидание

Заданный размер запаса уже достигнут либо для настроенного запроса нет шаблона.
<br/>

### Красное — не хватает компонентов

Системе не хватает компонентов для запуска текущего задания. Работа продолжится, как только в системе появится достаточно
компонентов.
<br/>

### Жёлтое — создание

Запрошенный ресурс сейчас создаётся. Запросчик ожидает завершения задания.<br/>
Пока активно это состояние, параметры соответствующего запроса в <ItemLink id="requester"/> заблокированы и изменить их
нельзя.
<br/>

### Фиолетовое — экспорт

<ItemLink id="requester"/> получил все результаты текущего задания и пытается экспортировать их в систему хранения.<br/>
Обычно это состояние почти незаметно. Если оно сохраняется надолго, в вашей системе хранения недостаточно места.
<br/>

### Внешний вид блока

Если хотя бы один запрос в <ItemLink id="requester"/> находится не в состоянии ожидания или пустоты, блок меняет внешний
вид.

## Терминал

Мод также добавляет <ItemLink id="requester_terminal"/>, позволяющий из одной точки обращаться ко всем
<ItemLink id="requester"/> в той же сети.

Терминал обладает теми же возможностями, что <ItemLink id="ae2:pattern_access_terminal"/>, и позволяет искать конкретный
запрос. По умолчанию все <ItemLink id="requester"/> называются одинаково, поэтому их запросы объединены под одним
заголовком. Чтобы выделить группу <ItemLink id="requester"/> в <ItemLink id="requester_terminal"/>, переименуйте их на
наковальне или с помощью <ItemLink id="ae2:name_press"/>.
