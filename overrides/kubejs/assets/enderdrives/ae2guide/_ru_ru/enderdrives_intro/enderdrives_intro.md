# Эндер-диски

Эндер-диски — мощные накопители, которые с помощью частот обеспечивают глобально синхронизированное хранилище между
ME-системами, измерениями и даже разными игроками.

## Принцип работы
У каждого EnderDrive настраиваются частота, область доступа и режим.
- **Частота**: диски с одной частотой используют общий инвентарь.
- **Область доступа**: определяет, кто может пользоваться диском (все, владелец или команда).
- **Режим**: управляет направлением предметов (двунаправленный, ввод или вывод).

Все диски с одинаковыми частотой и областью доступа обращаются к **одному виртуальному инвентарю** независимо от своего
местоположения.

## Ограничение типов
В отличие от обычных накопителей AE2, EnderDrive ограничивает только количество типов. Из-за внутреннего устройства
хранилища это единственное жёсткое ограничение: для каждого типа можно хранить до 2^63 - 1, то есть
9 223 372 036 854 775 807 предметов. Но будьте осторожны: энергопотребление растёт вместе с количеством предметов,
хранящихся на этой частоте!

У каждого сервера свой предел типов, после которого нагрузка становится заметной. Проверить сервер можно командой
«autobenchmark». Для точного результата держите открытым терминал с диском выбранной частоты и областью доступа «Личная».
Тест продолжается, пока TPS не упадёт ниже 18, и может занять несколько минут.

В среднем у автора предел составляет около 275 000 типов. 275 000 / 255 ≈ 1078. Это значит, что до появления проблем с
производительностью пришлось бы заполнить 107,8 ME-накопителя эндер-дисками 256k и предметами разных типов. Рекомендуемый
максимум может быть как выше, так и ниже. Ограничение общее для всех, кто использует эти диски в одном мире.

## Режимы диска
Для каждого диска можно выбрать один из трёх **режимов передачи**:

- ![Двунаправленный режим](../pic/transport_bidirectional_alt.png) **Двунаправленный** _(по умолчанию)_
  Обычное поведение ME-накопителя: предметы можно свободно помещать и извлекать.


- ![Режим ввода](../pic/transport_input_alt.png) **Только ввод**
  Предметы можно помещать, но нельзя извлекать. Полезно для буферов и синхронизации входящих предметов.


- ![Режим вывода](../pic/transport_output_alt.png) **Только вывод**
  Предметы можно извлекать, но нельзя помещать. Подходит для выходных буферов и доступа только для чтения.

## Область доступа и приватность

У каждого диска есть **область доступа**, определяющая, кто может пользоваться инвентарём:
-  **Общая** _(по умолчанию)_
   Публичный доступ. Любой игрок с той же частотой может пользоваться общим инвентарём.


-  **Личная**
  Привязана к вашему UUID. Только вы можете создавать диски с доступом к этой частоте, но другие пользователи вашей
  ME-системы всё равно могут обращаться к хранилищу.


-  **Командная**
  Доступ разделяется с вашей командой FTB. Все её участники могут создавать диски с доступом к той же частоте.
