# Опустошение и наполнение ячеек

Как быстро выгрузить ячейку в сундук, набор ящиков или рюкзак либо, наоборот, заполнить ячейку их содержимым?

Используйте <ItemLink id="io_port" /> и подсеть, ограничивающую места, куда он может помещать содержимое
либо откуда может его забирать.

## Настройки

* Для <ItemLink id="io_port" /> (1) кнопкой со стрелкой в центре интерфейса выбирается «Передать данные в сеть»
  либо «Передать данные в ячейку хранения». Для максимальной скорости установлены 3 карты ускорения.
* <ItemLink id="storage_bus" /> (2) имеет обычные настройки.

## Принцип работы

### Режим «Передать данные в сеть»

1. <ItemLink id="io_port" /> пытается выгрузить содержимое установленной
   [ячейки хранения](../items-blocks-machines/storage_cells.md) в
   [сетевое хранилище](../ae2-mechanics/import-export-storage.md).
2. Единственное хранилище подсети — <ItemLink id="storage_bus" />, которая помещает предметы, жидкости и прочее
   в установленную перед ней ёмкость.
* <ItemLink id="energy_cell" /> предоставляет достаточно большой буфер [энергии](../ae2-mechanics/energy.md),
  чтобы сеть не обесточилась из-за переноса множества предметов за каждый игровой тик.

### Режим «Передать данные в ячейку хранения»

1. <ItemLink id="io_port" /> пытается выгрузить содержимое
   [сетевого хранилища](../ae2-mechanics/import-export-storage.md) в установленную
   [ячейку хранения](../items-blocks-machines/storage_cells.md).
2. Единственное хранилище подсети — <ItemLink id="storage_bus" />, которая забирает предметы, жидкости и прочее
   из установленной перед ней ёмкости.
* <ItemLink id="energy_cell" /> предоставляет достаточно большой буфер [энергии](../ae2-mechanics/energy.md),
  чтобы сеть не обесточилась из-за переноса множества предметов за каждый игровой тик.
