# Кабельный якорь

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Небольшие декоративные шипы, устанавливаемые на кабель. С их помощью можно не дать кабелям соединиться, сделать
из кабелей лестницу или создать видимость крепления кабеля к окружающим стенам. Также используются для создания
<ItemLink id="facade" />.

Кабельные якоря не позволяют образовать соединение со стороны, на которой установлены.

По ним можно взбираться как по лестнице.
