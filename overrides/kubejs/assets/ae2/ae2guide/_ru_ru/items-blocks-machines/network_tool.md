# Сетевой инструмент

<ItemImage id="network_tool" scale="4" />

Сетевой инструмент — модифицированный [гаечный ключ](wrench.md), который также показывает диагностические сведения о сети
и хранит [карты улучшений](upgrade_cards.md). Он по-прежнему позволяет быстро разбирать блоки и снимать с кабеля
[компоненты](../ae2-mechanics/cable-subparts.md), но не может поворачивать блоки.

В нём 9 слотов для [карт улучшений](upgrade_cards.md). Эти карты доступны в интерфейсе любого устройства AE2,
пока инструмент находится где угодно в вашем инвентаре.

Щелчок правой кнопкой мыши по любой части сети открывает диагностическое окно, подобно щелчку по <ItemLink id="controller" />.
В окне отображаются:

*   количество используемых в сети каналов;
*   переключатель общей настройки отображения энергии в AE либо E/FE;
*   запас [энергии](../ae2-mechanics/energy.md) в сети и её максимальная энергетическая ёмкость;
*   количество поступающей и потребляемой сетью энергии;
*   список всех [устройств](../ae2-mechanics/devices.md) и компонентов сети.

Это окно также помогает определить, принадлежат ли два разных кабеля или устройства одной сети при работе с
[подсетями](../ae2-mechanics/subnetworks.md).

## Скрытие фасадов

<a href="facades.md">Фасады</a> скрываются, пока сетевой инструмент находится в любой руке.

С блоками за скрытыми фасадами можно взаимодействовать, не снимая фасады.
