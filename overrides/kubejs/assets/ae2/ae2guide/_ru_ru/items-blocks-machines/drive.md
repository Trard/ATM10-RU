# МЭ накопитель

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/drive.snbt" />
</GameScene>

МЭ накопитель — [устройство](../ae2-mechanics/devices.md), в которое устанавливаются [ячейки хранения](storage_cells.md),
чтобы использовать их как [сетевое хранилище](../ae2-mechanics/import-export-storage.md). В нём 10 слотов, каждый из которых принимает ячейку.

При необходимости ячейки можно помещать в его инвентарь и извлекать оттуда любой предметной логистикой, например воронками или шинами AE2.

МЭ накопитель можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

## Индикаторы состояния ячеек

На установленных в накопитель ячейках есть светодиоды, цвет которых показывает их состояние:

| Цвет      | Состояние                                                                                           |
| :-------- | :-------------------------------------------------------------------------------------------------- |
| Зелёный   | Пуста                                                                                                |
| Синий     | Содержит данные                                                                                      |
| Оранжевый | Закончились [типы](../ae2-mechanics/bytes-and-types.md), добавить новые типы нельзя                  |
| Красный   | Закончились [байты](../ae2-mechanics/bytes-and-types.md), поместить дополнительные предметы нельзя  |
| Чёрный    | Нет энергии или у накопителя нет [канала](../ae2-mechanics/channels.md)                             |

## Приоритет

Приоритет задаётся кнопкой с гаечным ключом в правом верхнем углу интерфейса. Поступающие в сеть предметы сначала направляются
в хранилище с наивысшим приоритетом. Если два хранилища или две ячейки имеют одинаковый приоритет, предпочтение отдаётся уже
содержащему этот предмет хранилищу. [Размеченные](cell_workbench.md) ячейки считаются уже содержащими подходящий под разметку
предмет, если входят в одну группу приоритета с другими хранилищами. Извлечение начинается с хранилища с самым низким приоритетом.
Таким образом, по мере помещения и извлечения предметов хранилища с высоким приоритетом заполняются, а хранилища с низким — опустошаются.
