# Кристальный резонирующий генератор

<BlockImage id="crystal_resonance_generator" scale="8" />

Это устройство вырабатывает энергию для МЭ сети без топлива. Из-за создаваемых им кристаллических колебаний в каждой сети
может работать только один такой генератор. Колебания проходят даже сквозь <ItemLink id="quartz_fiber" />.

**Скорость выработки:** <ae2:ConfigValue name="crystalResonanceGeneratorRate"/> AE/т
