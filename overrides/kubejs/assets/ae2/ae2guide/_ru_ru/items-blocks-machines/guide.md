# Руководство

<ItemImage id="guide" scale="8" />

### То самое руководство, которое вы сейчас читаете: здесь найдётся всё необходимое для знакомства с AE2.

* Откройте боковую панель слева, чтобы увидеть оглавление.
* На многих страницах есть интерактивные сцены. Если рядом со сценой отображаются кнопки ![Плюс](../assets/diagrams/plus.png)
  и ![Минус](../assets/diagrams/minus.png) (масштаб), камеру можно вращать и перемещать. Зажмите левую кнопку мыши
  и ведите мышь, чтобы вращать камеру; зажмите правую кнопку, чтобы перемещать её.
