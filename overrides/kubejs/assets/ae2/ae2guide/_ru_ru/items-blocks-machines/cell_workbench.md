# Верстак для ячеек

<BlockImage id="cell_workbench" scale="8" />

Верстак для ячеек позволяет настраивать [ячейки хранения](storage_cells.md) и <ItemLink id="view_cell" />.

Можно добавлять [карты улучшений](upgrade_cards.md) и настраивать «разметку», определяющую, что будет хранить ячейка.

Предметы и жидкости можно перетаскивать в слоты из JEI/REI, даже если у вас их на самом деле нет.

Щёлкните правой кнопкой мыши с ёмкостью для жидкости (например, ведром или резервуаром), чтобы выбрать фильтром саму
жидкость, а не предмет-ёмкость.

## Настройки

В левом верхнем углу интерфейса верстака для ячеек находится несколько кнопок:

*   Можно разметить ячейку на основе её текущего содержимого.
*   Можно очистить разметку ячейки.
*   Верстак можно настроить на сохранение разметки после извлечения ячейки, чтобы копировать настройки между ячейками.
