# Беспроводной терминал

<ItemImage id="wireless_terminal" scale="4" />


Беспроводные терминалы — переносные варианты обычных проводных [терминалов](terminals.md). Их интерфейсы полностью совпадают
с проводными аналогами, но вместо слотов для <ItemLink id="view_cell" /> в них находятся слоты для
[карт улучшений](upgrade_cards.md).

Чтобы связать терминал с сетью, поместите его в правый верхний слот <ItemLink id="wireless_access_point" />, подключённой
к этой сети. (Это слот с изображением беспроводного терминала и стрелкой под ним.)

Для работы терминал должен находиться в радиусе <ItemLink id="wireless_access_point" />.

Его запас энергии можно восполнить в <ItemLink id="charger" />.

# Беспроводной терминал

<ItemImage id="wireless_terminal" scale="4" />

Обычный терминал, но теперь переносной! Просматривайте и используйте содержимое
[сетевого хранилища](../ae2-mechanics/import-export-storage.md), а также запрашивайте ресурсы у системы
[автоизготовления](../ae2-mechanics/autocrafting.md) из любой точки в радиусе <ItemLink id="wireless_access_point" />.
