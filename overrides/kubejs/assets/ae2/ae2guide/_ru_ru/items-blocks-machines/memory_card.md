# Карта памяти

<ItemImage id="memory_card" scale="4" />

Карта памяти используется для копирования настроек между [устройствами](../ae2-mechanics/devices.md) AE2 и связывания
[P2P-туннелей](p2p_tunnels.md). С её помощью также можно устанавливать в устройства [карты улучшений](upgrade_cards.md).

- Shift + правая кнопка мыши — скопировать настройки или создать новую частоту связи P2P.
- Правая кнопка мыши — вставить настройки, карты улучшений или частоту связи.
