# МЭ сундук

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

МЭ сундук действует как миниатюрная сеть, объединяющая <ItemLink id="terminal" />, <ItemLink id="drive" /> и
<ItemLink id="energy_acceptor" />. Его можно использовать как небольшую сеть хранения, но возможность установить лишь одну
[ячейку хранения](../items-blocks-machines/storage_cells.md) заметно ограничивает пользу такого решения.

Зато он удобен для непосредственной работы с установленной внутрь ячейкой. Встроенный терминал видит и позволяет использовать
только содержимое установленной ячейки, а [устройства](../ae2-mechanics/devices.md) общей сети имеют доступ к предметам во всех
[сетевых хранилищах](../ae2-mechanics/import-export-storage.md), включая МЭ сундуки.

У блока 2 разных интерфейса, а доступ предметной логистики зависит от стороны. Взаимодействие с верхним терминалом открывает
встроенный терминал. Через эту сторону в установленную ячейку можно помещать предметы, но нельзя их извлекать. Взаимодействие
с любой другой стороной открывает интерфейс со слотом для ячейки и настройками приоритета. Предметная логистика может устанавливать
и извлекать ячейку только через сторону, на которой находится её слот.

МЭ сундук можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

Он имеет небольшой буфер энергии AE. Поэтому, если сундук не подключён к сети с [энергетической ячейкой](../items-blocks-machines/energy_cells.md),
одновременное помещение или извлечение слишком большого количества предметов может привести к временному отключению.

Терминал можно окрасить с помощью <ItemLink id="color_applicator" />.

## Настройки

МЭ сундук имеет те же настройки, что <ItemLink id="terminal" /> или <ItemLink id="crafting_terminal" />.
Однако он не поддерживает <ItemLink id="view_cell" />.

## Индикаторы состояния ячейки

У установленной в сундук ячейки есть светодиод, цвет которого показывает её состояние:

| Цвет      | Состояние                                                                                           |
| :-------- | :-------------------------------------------------------------------------------------------------- |
| Зелёный   | Пуста                                                                                                |
| Синий     | Содержит данные                                                                                      |
| Оранжевый | Закончились [типы](../ae2-mechanics/bytes-and-types.md), добавить новые типы нельзя                  |
| Красный   | Закончились [байты](../ae2-mechanics/bytes-and-types.md), поместить дополнительные предметы нельзя  |
| Чёрный    | Нет энергии или у ячейки нет [канала](../ae2-mechanics/channels.md)                                 |

## Приоритет

Приоритет задаётся кнопкой с гаечным ключом в правом верхнем углу интерфейса слота ячейки. Поступающие в сеть предметы сначала
направляются в хранилище с наивысшим приоритетом. Если два хранилища или две ячейки имеют одинаковый приоритет, предпочтение
отдаётся уже содержащему этот предмет хранилищу. [Размеченные](cell_workbench.md) ячейки считаются уже содержащими подходящий
под разметку предмет, если входят в одну группу приоритета с другими хранилищами. Извлечение начинается с хранилища с самым
низким приоритетом. Таким образом, по мере помещения и извлечения предметов хранилища с высоким приоритетом заполняются,
а хранилища с низким — опустошаются.
