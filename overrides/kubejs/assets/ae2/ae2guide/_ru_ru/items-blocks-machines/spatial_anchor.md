# Пространственный якорь

<BlockImage id="spatial_anchor" p:powered="true" scale="8"/>

Чтобы [устройства](../ae2-mechanics/devices.md) сети AE2 работали, чанки со всей сетью должны быть загружены; при загрузке
лишь части сеть может работать неправильно. Пространственный якорь решает эту проблему, принудительно загружая все чанки,
которые занимает его сеть. Даже одного кабеля, пересекающего границу чанка, достаточно для загрузки нового чанка.

«Загрузка» распространяется через [квантовые мосты](quantum_bridge.md), но не между измерениями. Поэтому для моста в Незер
понадобится по пространственному якорю в сети базы и в сети Незера.

По умолчанию якорь также включает случайные такты в загруженных чанках. Это можно отключить в конфигурации AE2.

Если зачем-то потребуется, его можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

## Настройки

*   Пространственный якорь предоставляет доступ к общей настройке отображения энергии в AE либо E/FE.
*   Можно включить внутриигровую голограмму загружаемых чанков.

## Энергия

Пространственный якорь расходует [энергию](../ae2-mechanics/energy.md) по следующей формуле:

e = 80 + (x\*(x+1))/2

где x — количество загружаемых чанков.
