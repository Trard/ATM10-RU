# Мод добавляет перечисленные ниже полезные возможности
## Умножение шаблонов в поставщиках: в поставщике шаблонов появляется кнопка для умножения или деления всех содержащихся в нём шаблонов
__Множители складываются!__

![Изменение количества шаблонов](assets/modify_patterns.png)
## Дополнительные режимы блокировки: во все поставщики шаблонов добавляются два новых режима
### Обычный: стандартный режим блокировки AE2. Шаблон отправляется, если подключённое хранилище не содержит ни одного из его исходных компонентов. Постороннее содержимое хранилища игнорируется и не мешает отправке шаблона.
    
![Обычный режим блокировки](assets/blocking/blocking_1.png)

### Полный: шаблон не отправляется, если в подключённом хранилище что-либо находится.
    
![Полный режим блокировки](assets/blocking/blocking_2.png)

### Умный: позволяет поставщику повторно отправить тот же шаблон, если в целевом хранилище находятся только исходные компоненты именно этого шаблона.

![Умный режим блокировки](assets/blocking/blocking_3.png)
