# Переносной накопитель

Переносной накопитель можно изготовить для транспортировки энергии в инвентаре. Чтобы зарядить или разрядить его, щёлкните ПКМ по любому стационарному накопителю.

<Recipe id="modern_industrialization:electric_age/battery/portable_storage_unit_asbl" />

Изначально у переносного накопителя нет ёмкости. Чтобы добавить её, установите аккумуляторы: щёлкните по накопителю ПКМ, держа аккумуляторы, либо щёлкните по аккумулятору, держа накопитель. Чем выше уровень аккумуляторов, тем больше будет ёмкость. Чтобы вернуть аккумулятор, щёлкните ПКМ по пустой ячейке, но вся лишняя энергия при этом будет потеряна.
