# Трубы

Трубы используются в рецептах некоторых машин, но их также можно размещать в мире. В пространстве одного блока помещается до 3 труб.

Трубы разных цветов не соединяются.

Щелчок ПКМ по трубе гаечным ключом изменяет тип соединения, а Shift+ПКМ снимает трубу.

## Жидкостные трубы

<ItemImage id="modern_industrialization:fluid_pipe" />

Жидкостные трубы могут содержать только один вид жидкости и по умолчанию не соединяются с пустыми трубами или блоками. Соединение можно создать принудительно: щёлкните гаечным ключом ПКМ по центру трубы либо щёлкните ПКМ по блоку, держа трубу. Во втором случае соединение появится, но предмет в руке не израсходуется.

## Предметные трубы

<ItemImage id="modern_industrialization:item_pipe" />

Предметные трубы по умолчанию не подключаются к инвентарям, но такое соединение тоже можно создать принудительно.

Щёлкните ПКМ по соединению без гаечного ключа, чтобы открыть фильтр. По умолчанию включён белый список, поэтому без настройки предметы не будут напрямую вставляться или извлекаться.

Разные виды труб работают немного по-разному.

Каждый тик жидкостные трубы пытаются равномерно извлечь жидкость из всех подключённых блоков, а затем равномерно распределить её. [Подробнее об их скорости читайте здесь.](../midgame/fluid_transfer.md)

Предметные трубы сначала вставляют предметы в инвентари с более высоким приоритетом и передают по 16 предметов раз в несколько секунд. **Их можно улучшать двигателями.**

## Примечание

Предметные трубы по умолчанию работают в режиме белого списка, то есть перемещают только предметы, указанные в фильтре. Переключитесь на чёрный список, чтобы перемещать только предметы, НЕ указанные в фильтре, либо добавьте нужный предмет в белый список. Не забудьте настроить обе стороны трубы, иначе предметы не будут перемещаться.
