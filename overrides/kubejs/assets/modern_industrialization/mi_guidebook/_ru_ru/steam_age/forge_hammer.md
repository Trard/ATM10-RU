# Начало работы

Прежде чем изготавливать бронзу, необходимо создать кузнечный молот. Он используется для базовых этапов обработки.

Поместив железную, медную или оловянную руду в кузнечный молот, вы получите по 2 единицы сырой руды из каждого блока. Это соотношение можно увеличить с помощью ручного молота. Каждую единицу сырой руды можно переплавить в слиток.

Ручной молот повышает выход кузнечного молота и открывает дополнительные рецепты, расходуя при этом прочность.

<Recipe id="modern_industrialization:materials/iron/craft/hammer" />

Теперь стоит задуматься о создании парового шахтёрского бура, чтобы добывать рудные блоки напрямую без кирки с «Шёлковым касанием».

<Recipe id="modern_industrialization:forge_hammer" />

Паровой шахтёрский бур добывает область 3×3 блока за один раз — идеальный инструмент для начала игры! Кроме того, у него есть «Шёлковое касание», отлично сочетающееся с кузнечным молотом.

<Recipe id="modern_industrialization:tools/steam_mining_drill" />

Для работы паровому шахтёрскому буру нужны и вода, и твёрдое топливо, например уголь.

Щёлкните ПКМ по источнику воды, чтобы заправить бур водой. Чтобы добавить топливо, в инвентаре щёлкните топливным предметом ПКМ по буру. Во время добычи топливо расходуется постепенно.
