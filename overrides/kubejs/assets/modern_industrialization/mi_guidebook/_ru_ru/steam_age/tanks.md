# Баки и бочки

Каждый бронзовый бак вмещает 4 ведра жидкости. Баками можно взаимодействовать с машинами и размещать их в мире.

Бронзовые бочки позволяют хранить и переносить 32 стопки одного предмета. Дополнительные сведения приведены на следующих страницах!

После установки бака в мире щёлкайте по нему ПКМ вёдрами или другими баками, чтобы переливать жидкости.

Баки с одинаковым содержимым можно складывать в стопки прямо в инвентаре. Удобно!

<Recipe id="modern_industrialization:materials/bronze/craft/tank" />

Щёлкните ПКМ по установленной бочке, чтобы положить в неё стопку предметов; удерживайте Shift, чтобы положить максимально возможное количество.

Щёлкните ЛКМ по установленной бочке, чтобы забрать стопку; удерживайте Shift, чтобы взять только 1 предмет.

<Recipe id="modern_industrialization:materials/bronze/craft/barrel" />

Сломанная бочка сохраняет содержимое и превращается в предмет, с которым можно взаимодействовать.

Щёлкните по предмету-бочке ПКМ другим предметом, чтобы поместить его внутрь.

Щёлкните предметом-бочкой ПКМ по пустой ячейке, чтобы извлечь часть содержимого.
