# Шина импорта-экспорта

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../structure/cable_import_export_bus.snbt"></ImportStructure>
</GameScene>

Шина импорта-экспорта объединяет <ItemLink id="ae2:import_bus" /> и <ItemLink id="ae2:export_bus" />. В фильтре задаются
экспортируемые стопки. Любую стопку, отсутствующую в фильтре, можно импортировать.
