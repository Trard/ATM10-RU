# Продвинутый кодировщик шаблонов

Чтобы указать продвинутому МЭ-поставщику шаблонов, к какой стороне направлять предметы, необходимо записать эту
информацию специальным устройством. Нажмите правой кнопкой мыши с ним в руке, чтобы открыть интерфейс.

<ItemImage id="advanced_ae:adv_pattern_encoder" scale="4"></ItemImage>

Закодированные шаблоны обработки можно поместить в левую ячейку. Устройство расшифрует их и отобразит список всех
исходных ингредиентов.

![Интерфейс продвинутого кодировщика](../pic/ape_pattern.png)

В каждой строке есть кнопки для всех граней блока, к которым можно направить ингредиент. Если оставить выбранной кнопку
«A», ингредиент будет отправлен к грани, непосредственно соединённой с поставщиком шаблонов. Выбор конкретной грани
заставит устройство вставлять предметы именно туда. Учтите: правильно расшифровать продвинутые шаблоны может только
<ItemLink id="advanced_ae:adv_pattern_provider" />. В других поставщиках шаблонов они действуют как обычные.
Кроме того, если к выбранной грани нельзя вставить хотя бы один предмет, направленная вставка не выполняется и
применяется стандартное поведение поставщика шаблонов.
