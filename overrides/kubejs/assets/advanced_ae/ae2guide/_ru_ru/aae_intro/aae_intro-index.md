# Advanced AE!

Advanced AE улучшает удобство работы с МЭ-системой и расширяет возможности систем поздней игры. Мод позволяет улучшать
поставщики шаблонов, чтобы направлять предметы к определённым сторонам целевых механизмов, и создавать многоблочные
компьютеры, способные выполнять неограниченное количество крафтов с общими сопроцессорами, пока хватает хранилища
крафта. Кроме того, он добавляет множество других полезных улучшений!
